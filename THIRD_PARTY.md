# Third-party sources

- PatchCore: https://github.com/amazon-science/patchcore-inspection ; fixed commit `fcaa92f124fb1ad74a7acf56726decd4b27cbcad`. Local upstream LICENSE is Apache-2.0. Upstream source and weights are excluded; clone separately, retaining its license, notices and attribution. Our scripts import the upstream implementation, not claim authorship of it.
- MVTec AD: MVTec dataset, CC BY-NC-SA 4.0. Experiments used a Voxel51 mirror; bitwise equality to the official archive has not been established. Original and derived images/masks are not redistributed. Obtain data under its original terms.
- Torchvision/ImageNet pretrained weights are downloaded separately, not bundled. Check original terms before use.
- Python packages retain their respective licenses. Dependency lists do not relicense packages.

Project code and notes were AI-assisted. No blanket license has yet been selected for original material; upstream terms remain unchanged. This release contains source and selected textual findings, not all raw experimental artifacts.
